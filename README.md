# Numera | Sorteador de números

Uma ferramenta simples e gratuita para sortear números dentro de um intervalo definido por você.

![Prévia do sorteador Numera](https://github.com/user-attachments/assets/6c9a0948-4ac3-4790-a855-46f1d1c940ef)

## Sobre o projeto

O Numera permite escolher quantos números sortear, definir os limites mínimo e máximo e decidir se os resultados podem se repetir. Depois do sorteio, é possível gerar um novo resultado com as mesmas configurações.

Este projeto foi desenvolvido como desafio prático da trilha Fullstack da Rocketseat.

## Como usar

1. Informe a quantidade de números que deseja sortear.
2. Defina o início e o fim do intervalo.
3. Marque **Não repetir número** para obter resultados únicos.
4. Clique em **Sortear**. Para gerar outro resultado, clique em **Sortear novamente**.

## Executar localmente

O projeto não exige instalação de dependências nem processo de build. Clone ou baixe este repositório e abra `index.html` no navegador.
